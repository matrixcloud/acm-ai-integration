# 拾光生活馆｜物流与配送知识库

> 用途：配送范围、运费、物流时效、丢件、签收、改址、拒收、破损、偏远地区。

# 物流公司
店铺常用承运商：
- 顺丰速运
- 京东物流
- 中通快递
- 圆通速递
- 韵达快递

普通订单不支持指定快递。
系统会根据仓库、目的地、商品属性和成本时效自动匹配。

# 运费规则

## 基础运费
实付满 69 元免基础运费。
实付不足 69 元，基础运费 6 元。

## 偏远地区
新疆、西藏、青海、内蒙古及部分偏远区域可能产生附加运费。
具体金额以下单结算页为准。

## 拆单运费
同一订单拆成多个包裹不会重复收取已经结算的基础运费。

# 运输时效

## 参考时效
- 江浙沪皖：1-2 天。
- 华东、华中、华南主要城市：2-3 天。
- 华北、西南、东北主要城市：2-4 天。
- 西北及部分偏远地区：3-6 天。

## 含锂电池商品
SG-1006 磁吸充电宝等含锂电池商品可能采用陆运，因此部分地区比普通商品多 1-2 天。

# 物流轨迹

## 发货后为什么没物流
生成运单号后还需要快递揽收和扫描。
通常 6-24 小时内会出现首条物流记录。

## 超过 48 小时无揽收
可联系客服核实是否漏揽、仓库错单或物流系统异常。

## 运输中 48 小时无更新
可先联系快递公司查询。

## 连续 72 小时无更新
若同时明显超过正常运输时效，可发起异常查件。

# 签收异常

## 显示签收但没收到
建议检查：
- 快递柜。
- 驿站。
- 门卫。
- 前台。
- 家门口。
- 家人、同事、邻居是否代收。
- 联系派件员确认投放位置。

如仍未找到，应尽快联系客服协助查件。

## 被别人代收
先联系代收人确认。
若用户本人并未授权且无法找回，可联系客服协助向快递公司反馈。

# 快递丢件

经承运商确认丢失后，店铺会根据库存和用户意愿安排：
- 补发。
- 退款。

用户无需承担快递运输过程造成的丢件损失。

# 包裹破损

## 外箱破损但商品完好
如商品本身正常使用，不需要售后。
建议仍保留外包装照片，以备后续发现隐性损伤时提供参考。

## 商品也破损
建议保留：
- 外包装照片。
- 面单照片。
- 商品破损照片。
- 开箱视频，如有。

核实后可安排补发、退款或换货。

# 少件与空包

## 少件
先确认订单是否拆分发货。
若全部包裹已签收仍少件，应提供外包装、面单、商品合照。

## 空包
保留完整包装和面单，尽快联系售后。
店铺会结合仓库出库重量、物流称重记录和视频记录核查。

# 错发

收到错误商品时：
- 不建议继续使用。
- 不要撕毁影响二次销售的标签。
- 拍摄商品、条码、面单。
- 联系客服。

经确认是仓库错发后，相关运费由店铺承担。

# 地址问题

## 地址写错
未出库时尽快联系客服尝试修改。
已出库后需要联系快递协商。

## 改址是否收费
快递公司可能根据实际线路收取改址费用。
具体以承运商规则为准。

## 无法配送
如果快递确认地址无法送达，包裹可能原路退回。
退回后可重新发货到可送达地址或退款。

因用户填写错误地址造成的重复运输费用，可能由用户承担。

# 拒收

拒收不等于立即退款。
包裹需要退回仓库并完成签收核验后再进入退款流程。

无正当理由拒收导致退回的，可能由用户承担退回运费。

# 仓库自提
不支持仓库自提。
仓库不对消费者开放现场取货。

# 学校、园区、部队地址
可否配送取决于当地网点和收发管理规则。
建议填写完整楼栋、宿舍、部门、园区等信息，并确保手机号可联系。

# 极端天气
台风、暴雨、暴雪、交通管制等情况可能影响仓库和物流时效。
此类不可抗力造成的正常延误通常不默认提供额外赔偿。

# 快递员服务问题
如果存在：
- 未联系直接放驿站。
- 服务态度差。
- 错误投递。
- 长时间不派送。

用户可先联系快递公司投诉，必要时店铺可协助反馈。

# 实时物流边界
具体物流节点、派件员电话、包裹当前位置、预计送达时间属于实时物流数据，应以快递系统或订单物流查询结果为准。
