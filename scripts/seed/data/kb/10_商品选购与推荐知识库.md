# 拾光生活馆｜商品选购与推荐知识库

> 用途：用户问“哪个适合我”“怎么选”“A 和 B 有什么区别”。

# 通勤人群推荐

## 通勤喝水
推荐 SG-1001 保温杯。
适合需要携带热水、咖啡或日常饮水的人群。

## 手机续航
推荐 SG-1006 磁吸充电宝。
适合支持磁吸无线充电的手机用户，也支持 USB-C 有线充电。

## 通勤包
推荐 SG-1007 帆布托特包。
适合轻量通勤、短途出门，不适合超重物品。

# 保温杯 vs 马克杯

## SG-1001
适合通勤、携带、保温。

## SG-1009
适合办公室、家庭固定场景，支持微波和洗碗机。

# 加湿器 vs 香薰扩香器

## SG-1010
主要功能是增加空气湿度。
不可加精油。

## SG-1002
主要功能是扩香和氛围。
可按说明加入水溶性香薰精油。

# 台灯适合谁
适合办公、阅读、学习桌面。
需要插电使用。

# 旅行烧水杯适合谁
适合经常出差、住宿，希望自行烧水的人。
只适用于 220V 电压环境。

# 充电宝适合谁
适合需要手机续航的人。
磁吸无线充电体验取决于手机型号、保护壳和磁吸对位。

# 收纳六件套适合谁
适合出差、旅游、搬宿舍时分类衣物。
只有轻度防泼水能力，不可当防水袋使用。

# 颈枕适合谁
适合飞机、高铁、汽车乘坐时短时支撑颈部。
不属于医疗矫正产品。

# 睡眠产品提示
SG-1015 真丝眼罩用于遮光和提升睡眠环境舒适度，不具备治疗失眠或其他医疗效果。

# 推荐原则
客服推荐商品时，应基于：
- 使用场景。
- 预算。
- 功能需求。
- 使用限制。

不应夸大商品效果，不应作医疗或绝对效果承诺。
