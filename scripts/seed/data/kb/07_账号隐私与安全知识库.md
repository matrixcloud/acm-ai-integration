# 拾光生活馆｜账号、隐私与安全知识库

> 用途：登录、手机号、账号注销、隐私、反诈骗、风险操作。

# 手机号用途
手机号主要用于：
- 登录验证。
- 订单通知。
- 配送联系。
- 账号安全验证。
- 售后沟通。

# 登录异常

## 收不到验证码
可检查：
- 手机信号。
- 短信拦截。
- 是否频繁请求验证码。
- 手机号是否填写正确。
- 运营商短信延迟。

连续多次请求可能触发短时限制。

## 更换手机号
通常需要在账号安全页面完成身份验证后修改。
无法自行修改时可联系人工客服核验。

# 账号注销

## 注销条件
通常要求：
- 没有未完成订单。
- 没有进行中售后。
- 没有未结算资金争议。
- 完成必要验证。

## 注销后数据
部分订单、财务、发票等数据会依据法律法规保留一定期限。

# 隐私

店铺仅在履行订单和提供服务所需范围内处理必要信息，包括：
- 收货人。
- 手机号。
- 地址。
- 订单信息。
- 售后记录。

# 客服绝不会索要
- 支付密码。
- 银行卡密码。
- 完整短信验证码。
- 私人银行账户密码。
- 与客服服务无关的身份证正反面。

# 私下转账
正规订单和售后款项应通过官方页面完成。
客服不会要求向个人微信、支付宝或银行卡转账。

# 常见诈骗

## 冒充客服退款
陌生人称商品有质量问题，要用户下载会议软件、屏幕共享、操作银行卡，属于高风险诈骗特征。

## 关闭百万保障
陌生电话要求关闭“百万保障”、会员扣费等并指导转账，常见于诈骗。

## 先转账后退款
正规客服不会要求用户先汇款才能获得退款。

## 安全账户
不存在所谓“客服安全账户”要求用户转钱进行资金验证。

# 风险提示
遇到可疑情况：
1. 停止操作。
2. 不点击陌生链接。
3. 不开启远程控制。
4. 回官方商城页面联系客服核实。
5. 如已发生资金损失，及时联系支付平台、银行及有关部门。

# 账号实时信息边界
登录状态、手机号绑定、注销进度、积分和会员等信息以账户系统实时数据为准。
