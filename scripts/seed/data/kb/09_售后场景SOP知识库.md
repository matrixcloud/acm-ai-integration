# 拾光生活馆｜售后场景 SOP 知识库

> 用途：复杂售后场景的标准处理思路，适合客服机器人检索后组织回复。

# 场景：用户说保温杯漏水
1. 确认杯盖是否旋紧。
2. 确认密封圈是否装好。
3. 确认杯口是否有异物。
4. 如仍漏水，请用户拍摄漏水视频。
5. 30 天内非人为问题可进入质量售后。

# 场景：充电宝发热
轻微温热：说明充放电过程中可能正常。
明显烫手：建议停止使用并观察。
出现鼓包、异味、冒烟：立即停止使用和充电，远离易燃物，转人工高优先级处理。

# 场景：加湿器不喷雾
1. 确认是否加入清水。
2. 棉芯首次使用需浸泡 3-5 分钟。
3. 检查供电。
4. 检查棉芯安装。
5. 如仍不工作，提供故障视频申请售后。

# 场景：扩香器不出雾
1. 水量是否正常。
2. 电量是否充足。
3. 上盖是否正确安装。
4. 雾化片是否有水垢。
5. 不建议直接加纯精油。

# 场景：台灯不开机
1. 检查 USB-C 线。
2. 更换电源适配器。
3. 确认插座正常。
4. 如仍无法开机，录制故障视频。
5. 12 个月内可申请有限质保。

# 场景：收到破损马克杯
1. 保留外包装。
2. 拍面单。
3. 拍商品破损位置。
4. 如有开箱视频一并提供。
5. 可根据情况补发或退款。

# 场景：衣物除毛器损伤衣服
先确认面料类型和使用方式。
薄纱、蕾丝、粗针织等不建议使用。
如设备本身存在异常刀头或结构问题，转质量售后判断。
如因不适合面料或使用不当导致，通常不属于商品质量问题。

# 场景：物流三天没动
如果连续 72 小时无更新且已经明显超过正常时效，应协助发起查件。

# 场景：显示签收但没收到
1. 查快递柜。
2. 查驿站。
3. 查门卫或前台。
4. 问家人代收。
5. 联系派件员。
6. 仍未找到则发起物流查件。

# 场景：用户说少发一件
1. 先查是否拆单。
2. 确认所有包裹是否签收。
3. 收集外包装、面单、商品合照。
4. 仓库核查。
5. 确认少发后补发或退款。

# 场景：用户说发错货
1. 建议不要使用。
2. 保留标签。
3. 拍商品和面单。
4. 核实仓库记录。
5. 确认错发后店铺承担相关运费。

# 场景：用户无理由退货
1. 确认签收时间。
2. 确认是否在 7 天内。
3. 确认商品是否完好。
4. 告知用户退货运费通常自理。
5. 引导从售后入口申请。

# 场景：用户用了三个月坏了
先判断商品是否属于 12 个月质保电器。
若属于，进入质保排查。
若不属于长期质保商品，则根据商品售后期限和实际故障评估。

# 场景：用户声称要投诉 12315
1. 不争辩。
2. 询问具体订单与问题。
3. 记录用户诉求。
4. 如已有售后记录，查询处理经过。
5. 转人工或高级客服复核。

# 场景：用户情绪激动
回复重点：
- 先确认问题本身。
- 不与用户争论。
- 不反复机械重复政策。
- 给出下一步可执行方案。
- 涉及实时订单时转入系统查询。

# 场景：用户要求赔偿 500 元
普通客服不能自行承诺规则外补偿。
应说明需要依据实际损失、平台政策和审核结果处理。
必要时转人工。

# 场景：用户拒绝提供任何证据
应说明部分售后需要必要证据才能判断问题，例如破损、漏水、故障。
尽量只要求与判断直接相关的最少材料。
如果用户仍拒绝，可转人工处理。

# 场景：退货已经寄回但没退款
需查询：
- 退货物流是否签收。
- 仓库是否验收。
- 售后是否通过。
- 是否已发起退款。

以上均为实时状态，不能仅用通用时效推断。

# 场景：订单扣款两次
高优先级核实支付流水。
不要建议用户继续支付。
应收集两笔支付记录并查询支付系统。

# 场景：用户收到诈骗电话
明确提醒：
- 不转账。
- 不下载陌生远程控制软件。
- 不提供验证码。
- 回官方订单页面联系店铺。
