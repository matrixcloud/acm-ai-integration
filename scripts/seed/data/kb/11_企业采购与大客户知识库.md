# 拾光生活馆｜企业采购与大客户知识库

> 用途：企业批量采购、礼品采购、开票、交付、定制咨询。

# 企业采购门槛
单次采购 50 件以上，可申请企业采购服务。

# 常见企业采购场景
- 员工福利。
- 活动礼品。
- 客户礼赠。
- 展会物料。
- 办公室用品。
- 入职礼包。

# 可批量采购商品
原则上在售商品均可申请批量采购，但最终取决于：
- 实际库存。
- 交货时间。
- 商品批次。
- 物流能力。

# 企业采购价格
大批量采购可能提供阶梯报价。
具体价格需根据 SKU、数量、交期、是否含税等确认。

# 模拟阶梯规则
以下仅用于知识库模拟：

## 50-99 件
日常售价基础上约 95 折起。

## 100-299 件
日常售价基础上约 92 折起。

## 300 件以上
由企业采购专员单独报价。

具体最终价格以实际报价单为准。

# 定制服务
部分商品可支持：
- 定制卡片。
- 定制外包装贴纸。
- 简单 Logo 丝印。

是否支持取决于商品类型和起订量。

# 定制起订量
普通印刷类定制通常 200 件起。
特殊工艺可能要求更高起订量。

# 定制交期
一般比现货采购多 7-15 个工作日。
复杂定制可能更长。

# 企业发票
支持按实际交易开具电子普通发票。
如未来开通专票，以企业采购页面为准。

# 企业订单物流
大批量订单可能：
- 分批发货。
- 使用整车或零担物流。
- 多仓发货。

# 企业订单退换货
非质量问题的定制商品通常不适用普通无理由退货。
质量问题仍按实际质量责任处理。

# 企业采购人工服务
企业大客户采购建议转人工或企业采购专员处理，尤其涉及：
- 数量大于 100。
- 定制。
- 特殊交期。
- 合同。
- 对公付款。
- 多地址配送。
