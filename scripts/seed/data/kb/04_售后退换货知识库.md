# 拾光生活馆｜售后退换货知识库

> 用途：七天无理由、质量问题、退货、退款、换货、保修、破损、少件、错发、费用承担。

# 七天无理由退货

## 基本规则
符合条件的普通商品支持自签收次日起 7 天内申请无理由退货。

## 时间计算
例如 8 月 1 日签收，则 8 月 2 日算第 1 天。

## 商品要求
商品应：
- 保持完好。
- 配件齐全。
- 说明书齐全。
- 赠品完整。
- 无明显使用痕迹。
- 不影响二次销售。
- 无人为损坏。

## 拆物流包装
拆开快递外包装不影响退货资格。

## 商品包装拆了
如果拆除商品包装、封签、保护膜会导致商品价值明显降低或影响二次销售，则可能不符合无理由退货条件。

## 使用过
必要检查性质的轻度试用不等同于长期使用。
如出现明显污渍、磨损、异味、划痕等，可能无法按无理由退货处理。

# 不适用无理由的典型情况
- 已明显使用并影响二次销售。
- 人为损坏。
- 定制类商品。
- 法律法规规定不适用的商品。
- 商品页明确且合法标注不支持无理由的特殊商品。

# 无理由退货运费
非质量问题退货，退回运费通常由用户承担。

# 无理由换货运费
用户通常承担寄回运费。
店铺承担一次重新寄出的基础运费。
反复更换规格可能需要用户承担额外运费。

# 质量问题

## 常见质量问题
- 核心功能无法正常实现。
- 正常使用出现异常断裂。
- 电器无法正常开机。
- 正常密封情况下漏水。
- 明显制造缺陷。
- 收到即严重破损。
- 与商品核心描述明显不符。

## 通常不属于质量问题
- 个人不喜欢。
- 轻微色差。
- 合理尺寸误差。
- 正常工艺痕迹。
- 强风导致伞骨损坏。
- 私自拆机。
- 进水。
- 人为跌落。
- 使用不匹配电源。
- 未按说明使用。

# 质量问题运费
经确认属于质量问题，合理退换货物流费用由店铺承担。

# 证据材料
根据问题可能需要：
- 商品整体照片。
- 故障部位照片。
- 故障视频。
- 商品标签。
- 快递面单。
- 外包装照片。
- 电源线材测试说明。

# 退货流程

1. 用户发起售后申请。
2. 系统或客服审核。
3. 用户按照售后页面指定地址寄回。
4. 用户填写退货物流单号。
5. 仓库签收。
6. 仓库验收。
7. 退款或换货。

# 退货地址
必须以当次售后页面生成的地址或客服提供的售后地址为准。
不要自行寄到旧地址或发货面单地址。

# 是否可以到付
除非售后页面或客服明确允许，否则不要擅自到付。
未经确认的到付件可能被拒收。

# 退货到仓后的处理
仓库签收后通常 1-3 个工作日完成验收。
验收通过后再进入退款或换货流程。

# 换货

## 可换颜色或规格
在目标规格有库存且符合售后条件时可以申请。

## 换货库存
不长期预留。
如果仓库验收完成时目标规格缺货，可改为其他规格或退款。

## 换货发出时效
验收通过后通常 1-2 个工作日内重新发出。

# 退款

## 店铺审核
普通售后申请一般 1-2 个工作日完成初步审核。

## 到仓验收
通常 1-3 个工作日。

## 原路到账
店铺发起退款后，通常 1-7 个工作日到账。

## 银行卡
部分银行可能处理更慢。

## 退款路径
原则上原路退回，不支持自行指定其他银行卡、微信或支付宝。

# 退款金额

退款可能低于商品标价的原因：
- 优惠券分摊。
- 部分退款。
- 用户承担退货运费。
- 特殊不可退费用。
- 订单级活动折扣。

# 优惠订单退款
使用优惠券后，优惠通常会分摊到各商品。
部分退款时按商品实际支付金额退款，而不是原价。

# 发错货
经确认仓库错发：
- 退回运费由店铺承担。
- 重新发货运费由店铺承担。

# 少件
确认缺少后可：
- 补发。
- 退款对应商品金额。

# 运输破损
确认是运输造成的破损，店铺会协助处理并承担合理售后成本。

# 有限质保范围
正常使用和遵循说明书情况下，由产品材料或制造原因导致的功能故障，可视情况提供：
- 维修。
- 换货。
- 配件补发。
- 其他合理方案。

# 不属于质保
- 摔落。
- 液体进入。
- 私拆。
- 改装。
- 异常电压。
- 人为挤压。
- 非正常使用。
- 自然磨损。

# 保修不等于一定换新
店铺会根据使用时间、故障程度、备件和维修可行性确定方案。

# 包装盒丢失
质量问题售后不能仅因为包装盒丢失而一概拒绝。
但无理由退货可能因包装不完整影响二次销售判断。

# 安全风险售后

## 充电宝鼓包
立即停止使用和充电。
不要挤压、针刺、拆解。
远离易燃物并联系客服。

## 电器冒烟
立即断电。
不要反复通电测试。
保证人员安全后联系客服。

## 漏电
立即停止使用并断电。

# 售后实时边界
具体某笔售后：
- 是否审核通过。
- 是否收到退货。
- 当前退款阶段。
- 换货是否出库。
- 实际退款金额。

均属于实时数据，应以售后系统为准。
